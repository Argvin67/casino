# Casino (Fabric 1.21.1)

Предмет: Казино-фишка (casino:chip), вкладка "Казино" в творческом режиме.
ПКМ с фишкой в руке - открывает меню казино. Также команда /casino.
Крафт: 1 изумруд = 9 фишек, 9 фишек = 1 изумруд (шапелес, в верстаке).

Окна (обычные окна сундука, кнопки - предметы):
- /casino            - главное меню
- /casino coinflip   - монетка (переключатель Орёл/Решка)
- /casino slots      - слот-машина (анимация барабанов)
- /casino roulette   - рулетка (красное/чёрное/чёт/нечёт/1-18/19-36/зеро/число)
- /casino blackjack  - блэкджек (Взять / Хватит / Удвоить)
- /casino balance    - баланс

Нижний ряд каждой игры - панель ставки: -100 -10 -1 [ставка] +1 +10 +100, баланс, назад.
Мод должен стоять и на сервере, и у клиентов (предмет и текстура).

Сборка: Java 21 + Gradle 8.8+  ->  gradle build  ->  build/libs/casino-1.0.0.jar
